## この資料の正本責務

このファイルが単一の正本として持つもの: 運用上の作業キュー — 進行中・
ブロック中・完了のタスク。持たないもの: 要件レベルの完了状況
（`docs/REQUIREMENTS.md` の受け入れ基準表が正本）、現在地
（`HANDOFF.md`）、経緯（`docs/REPORT.md` と git log）。台帳と実状態
（open PR・CI）が食い違ったら実状態が正。

<注: `docs/REPORT.md` の雛形は同梱されていない — この参照は、この
リポジトリで経緯の役割を担うものに合わせて調整する（小規模なら
git log と PR 本文で代替可）。>
